## 🚀 Hướng dẫn sử dụng

### Cách 1: Mở trực tiếp (Nhanh nhất)
1. Giải nén tệp `pink_roses_project.zip`.
2. Nhấp đúp chuột vào tệp **`index.html`** để mở trên bất kỳ trình duyệt nào (Chrome, Edge, Cốc Cốc, Safari, Firefox).
3. Chạm hoặc nhấp vào màn hình để kích hoạt âm nhạc và hiệu ứng hoa hồng phát sáng lung linh.

### Cách 2: Chạy qua Python
Mở Terminal / Command Prompt tại thư mục dự án và chạy lệnh:
```bash
python pink_roses.py
```
Trình duyệt sẽ tự động mở trang web tại địa chỉ `http://localhost:8088`.
